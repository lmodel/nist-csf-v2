# References

* [NIST CSWP 29, the CSF 2.0](cswp-29.md) - NIST Cybersecurity White Paper 29, The NIST Cybersecurity Framework (CSF) 2.0 (February 26, 2024, <https://doi.org/10.6028/NIST.CSWP.29>), the edition the schema renders: a taxonomy of cybersecurity outcomes in six functions, 22 categories and 106 subcategories, with Profiles and Tiers for using it and a glossary.
* [NIST's CSF website](csf-site.md) - NIST's Cybersecurity Framework website, <https://www.nist.gov/cyberframework>: the publication, the Quick Start Guides, the Profiles, the Informative References it calls Mappings, and the community profiles, which the schema does not model.

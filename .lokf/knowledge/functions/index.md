# Functions

* [GOVERN](govern.md) - The CSF 2.0 function GV, GOVERN: the organization sets, communicates and monitors its strategy, expectations and policy for managing cybersecurity risk. It holds 6 categories, 31 subcategories and 119 implementation examples.
* [IDENTIFY](identify.md) - The CSF 2.0 function ID, IDENTIFY: the organization understands its current cybersecurity risks. It holds 3 categories, 21 subcategories and 74 implementation examples.
* [PROTECT](protect.md) - The CSF 2.0 function PR, PROTECT: the organization uses safeguards to manage its cybersecurity risks. It holds 5 categories, 22 subcategories and 77 implementation examples.
* [DETECT](detect.md) - The CSF 2.0 function DE, DETECT: the organization finds and analyzes possible cybersecurity attacks and compromises. It holds 2 categories, 11 subcategories and 37 implementation examples.
* [RESPOND](respond.md) - The CSF 2.0 function RS, RESPOND: the organization takes action on a detected cybersecurity incident. It holds 4 categories, 13 subcategories and 38 implementation examples.
* [RECOVER](recover.md) - The CSF 2.0 function RC, RECOVER: the organization restores the assets and operations a cybersecurity incident affected. It holds 2 categories, 8 subcategories and 18 implementation examples.

# Datasets

* [nist-csf-v2 LinkML schema](nist-csf-v2-linkml-schema.md) - The LinkML schema of the Cybersecurity Framework (CSF) 2.0, `src/nist_csf_v2/schema/nist_csf_v2.yaml` (schema id `https://w3id.org/lmodel/nist-csf-v2`, version 2.0.0): five classes, one enum with the value `withdrawn` and six identifier types. Its `lokf adapt` copy `.lokf/nist-csf-v2.yaml`, rooted on the function, the category and the subcategory, is the bundle's domain schema.
* [NIST's CSF 2.0 catalog copy](csf-catalog-copy.md) - NIST's catalog of the Cybersecurity Framework (CSF) 2.0 in the Open Security Controls Assessment Language (OSCAL), copied with NIST's licence from usnistgov/oscal-content v1.6.0 into `src/nist_csf_v2/schema/oscal-content/` and matched to that release by git object hash. The tests derive the whole framework from it, withdrawn CSF 1.1 elements included.
* [Generated artefacts](generated-artefacts.md) - What the LinkML generators and `lokf adapt` write from the schema: `project/` (JSON Schema, OWL, SHACL, ShEx, JSON-LD, GraphQL, protobuf, SQL, TypeScript, Excel and Java), the Python dataclasses and Pydantic models in `src/nist_csf_v2/datamodel/`, `docs/schema/` and `docs/elements/`, and `.lokf/nist-csf-v2.yaml`. None is edited by hand.
* [Test data and tests](test-data.md) - The schema's tests: seven valid examples and 29 counter-examples under `tests/data/`, `tests/test_data.py`, which holds each to the validator, `tests/test_upstream.py`, which derives the framework from NIST's catalog and holds the examples to it, `tests/test_watch.py`, which runs the upstream watch against stubbed answers, and `tests/test_schema_rules.py`, which holds the adapt copy apart from LOKF and the slsa, github-actions, oscal, spdx and nist-sp-800-218 copies in `tests/neighbours/`.
